<a id="المسارات-العامة-المفتوحة"></a>
## المسارات العامة المفتوحة

<a id="فحص-الجاهزية-والاتصال"></a>
### 1. فحص الجاهزية والاتصال

التحقق من اتصال الخادم وقاعدة بيانات SQLite:
- **المسار:** `/api/health`
- **النوع:** `GET`
- **المصادقة:** عام بدون مصادقة
- **الاستجابة:**
  ```json
  {
    "ok": true
  }
  ```

---

<a id="صفحة-التحقق-من-الوثيقة-الموقعة"></a>
### 2. صفحة التحقق من الوثيقة الموقعة

عرض شهادة التحقق الجنائية الكاملة للعقد الموثق برمز التحقق (مثال: `MG35RR0RJ8YX`):
- **المسار:** `/v/:code`
- **النوع:** `GET`
- **المصادقة:** عام بدون مصادقة
- **الاستجابة:** `200 OK` (صفحة ويب كاملة متوافقة مع الوضع الليلي تحتوي باركود Code39 وتفاصيل الموقعين وبصمة التجزئة SHA-256).

---

<a id="بوابة-البحث-والتحقق"></a>
### 3. بوابة البحث والتحقق

بوابة عامة تتيح للمستخدم إدخال رمز أي وثيقة أو مسح الباركود للتحقق الفوري من صحتها:
- **المسار:** `/verify`
- **النوع:** `GET`
- **المصادقة:** عام بدون مصادقة

---

<a id="بوابة-توقيع-العميل"></a>
### 4. بوابة توقيع العميل

بوابة التوقيع الإلكتروني المؤمنة للعميل والممثلين لمراجعة شروط العقد، التحقق بالرمز السري، وإتمام التوقيع:
- **المسار:** `/s/:token`
- **النوع:** `GET`
- **المصادقة:** معتمد على الرمز السري المرمّز بـ HMAC.

---

<a id="المسارات-الإدارية-المحمية"></a>
## المسارات الإدارية المحمية

كافة المسارات الإدارية تتطلب جلسة مستخدم نشطة عبر ملف تعريف الارتباط (`dossier_session`).

<a id="توليد-pdf-للعقد"></a>
### 1. توليد PDF للعقد
- **المسار:** `/api/contracts/:id/pdf`
- **النوع:** `GET`
- **الاستجابة:** دفق ملف بصيغة `application/pdf`.

<a id="توليد-pdf-للفاتورة"></a>
### 2. توليد PDF للفاتورة
- **المسار:** `/api/invoices/:id/pdf`
- **النوع:** `GET`
- **الاستجابة:** دفق ملف بصيغة `application/pdf`.

<a id="توليد-سند-القبض"></a>
### 3. توليد سند القبض
- **المسار:** `/api/invoices/:id/receipt/pdf`
- **النوع:** `GET`
- **الاستجابة:** دفق ملف بصيغة `application/pdf`.
